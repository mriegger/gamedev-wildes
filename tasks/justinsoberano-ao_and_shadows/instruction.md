# Task 001 - Ambient Occlusion and Shadows

Add real time ambient occlusion and soft visible shadows without changing gameplay or art direction of this game. Keep Godot 4.7 compatibility renderer. 

Ambient occulusion should ground block seams, corners, and the explorer's feet while leaving open ground clean. Terrain, trees, the explorer, and placed blocks must cast subtle shadows through every camera rotation and zoom. 

Mining, placing, falling, pausing, returning, and creating a world must leave lighting correct. Please avoid acne, detached shadows, crushed colors, halos, or obvious performance loss when implementing this. 

Make sure to run the game and check that there are no errors or warnings.
