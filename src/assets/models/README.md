# Model Assets – Wildes

- `tools/hoe/copper_hoe.glb` provides the held copper hoe model.
- `farming/pumpkin/*.fbx` provides four pumpkin growth stages, a mature crop, and a harvested state.
- `foraging/apple/apple.glb` and `foraging/apple/Textures/colormap.png` provide the apple model used on trees, on the ground, and for the derived inventory icon.
