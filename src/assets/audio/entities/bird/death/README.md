# Bird Death Audio

`bird_death_squawk_CC0.wav` is a short processed excerpt of `crow_sampled_caw_03_CC0.ogg` from the existing crow vocalization pack. The edit trims the source, filters low frequencies, adjusts its level, and adds short fades for use as a one-shot bird death squawk.
