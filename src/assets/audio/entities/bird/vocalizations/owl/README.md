# Owl Vocalizations

These game-ready owl hoots were sampled from real BigSoundBank / LaSonotheque
recordings and edited as dry 48 kHz audio. They are released under
[CC0 1.0 Universal](https://creativecommons.org/publicdomain/zero/1.0/).
Attribution is not required and is recorded here for provenance.

All source recordings are by Joseph SARDIN and were retrieved on 2026-08-20.

| File | Source recording | Processing |
| --- | --- | --- |
| `owl_sampled_hoot_01_spotted_CC0.ogg` | [Tawny Owl #1 (s1763)](https://bigsoundbank.com/tawny-owl-1-s1763.html) | Edited as the closest available CC0 proxy for a Spotted Owl; trimmed, filtered, faded, normalized, and converted to 48 kHz Ogg Vorbis. |
| `owl_sampled_hoot_03_boreal_CC0.ogg` | [Tawny Owl #3 (s3459)](https://bigsoundbank.com/tawny-owl-3-s3459.html) | Edited as the closest available CC0 proxy for a Boreal Owl; trimmed, filtered, faded, normalized, and converted to 48 kHz Ogg Vorbis. |
| `owl_sampled_hoot_distant_CC0.ogg` | [Tawny Owl #1 (s1763)](https://bigsoundbank.com/tawny-owl-1-s1763.html) | Distant woodland variant derived from the first clip with filtering and short delays. |
